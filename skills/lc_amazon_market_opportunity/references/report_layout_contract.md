# 两轮复评 HTML 版式契约

## 版本与边界

- 固定版本：`two-round-competition-v1`；由 `tools/niche_two_round_report.py` 的 `REPORT_LAYOUT_VERSION`、`COMPETITION_LAYOUT` 和 `_competition_environment` 唯一实现。
- 数据只能替换内容、数值、缺失状态、Top3 数量和透视行；不得改变页面层级、标题、板块顺序、卡片数量、表头、颜色体系、断点或组件名称。
- 新报告必须是自包含 HTML：CSS、透视切换脚本和 ASIN 复制脚本均由渲染器输出；不得依赖浏览器运行时补丁、外链资源或人工复制旧报告样式。

## 固定页面顺序

1. `细分市场 Top3 与进一步分析`：评分口径说明。
2. `粗筛：直接确定 Top3`：候选评分表及按排名展开的 Top3 卡片。
3. `进一步分析：关键词覆盖与广告压力`：固定七列表。
4. `Top3 细分市场竞争环境分析`：按冻结排名逐张复评卡。
5. 固定运行 ID、复评运行 ID 与规则版本回执。

每张复评卡保持以下顺序：需求定义与证据 → 基础统计与风险说明 → 关键词明细与 Top20 → `细分市场竞争环境分析`（市场解读、四张摘要卡、8 项规则结论、基础维度透视）。

## 固定表格

### 关键词与广告指标

列顺序永远为：`细分市场`、`核心词数`、`参与词数`、`商品均价`、`加权CPC`、`90天转化率`、`广告压力`。

- 第一列宽度为 22%，左对齐；其余六列各 13%，居中。
- 采用 `table-layout: fixed`；表头和正文共用同一列轨道。
- 表头、正文及 caption 均有细边框；窄屏最小宽度 760px，并保留横向滚动。

### 8 项规则结论

列顺序永远为：`指标`、`规则值`、`等级`、`读数`、`口径`；8 行顺序永远为评论依赖性、评分值依赖性、价格敏感度、最值得进入的价格带、新品打造周期、商品垄断度、品牌垄断度、广告压力指数。

## 竞争环境卡

- 市场解读区固定含竞争结构、获客成本、新品信号、数据覆盖四行。
- 摘要区固定为四张卡：市场规模、价格与获客、竞争集中、进入窗口。
- 基础维度透视固定四个页签：评论数、上架天数、评分、售价；每页固定显示供给／销量双轨、Listing 占比、销量占比、Listing 数、平均月销量和供需比。字段缺失时仅显示同位置的“暂无法生成透视”，不得隐藏或替换页签。

## 变更规则

- 改动此版本的任何 DOM 结构、标题、表头、CSS token、响应式断点或组件顺序，必须新建版本号与迁移测试；不得静默修改 `two-round-competition-v1`。
- 仅修正文案、颜色细节或计算字段时，必须同时更新渲染器、此契约和 `tests/test_niche_two_round_report.py`。

## 文案修正记录（v1 结构不变）

2026-10-03 仅修正与现行规则不符的文字，DOM 结构、表头、CSS 与板块顺序均未改变（已用同一数据对比原渲染器，标签序列一致）：

- 等待补表提示：改为“请为上述 N 个市场各提供 1 份关键词转化表和 1 份卖家精灵关键词反查表，共 2N 个 Excel”。
- 卡片商机行说明：改为“商机表对应：第 N 行，仅作需求证据与风险参考”；多维组合候选显示“没有商机表行”。
- 广告说明：改为只用同时有转化数据和卖家精灵建议竞价的关键词，出价只取卖家精灵表。
- 冲突原因：由原始字典改为可读中文，最多列出重叠最高的 3 个。

候补、进入建议／风险等级、广告低覆盖只写入 JSON 产物，不在报告中展示。
