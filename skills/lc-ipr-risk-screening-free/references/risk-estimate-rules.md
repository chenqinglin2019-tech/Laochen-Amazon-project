# 五级风险预判：evidence-estimate-v1 / known-findings-risk-v1

## 新任务与显式重评：known-findings-risk-v1

新任务默认 `assessment_revision=known-findings-risk-v1`，运营报告默认 `presentation_policy_revision=operator-report-v1`。以下规则不按完成率或置信度机械改变已查明的风险等级；无依据仍待定。历史任务不会自动迁移；用户明确要求重评时，从原材料建立新版本，保留旧报告与原审阅签名。

- 总体及情景取已查明、适用于本次行为的具体当前风险最高级；没有完成复核的适用判断时，`risk:null`、`risk_basis:insufficient_evidence`，运营展示“风险待定／暂缓上架”。有适用的低／极低依据而无中高风险时，可给本轮已查结果的低风险预判；未完成项仍影响上架建议，不声称未查询范围已排除侵权。
- 未执行、失败、限额、缺字段、未知权属、未取得设计图或产品内部资料只进入进度、已查／未完成事项和待判断候选；不参与等级计算，不设最低完成率，不因缺口把已查明的中高风险清空。实际非法身份、错号、地域混用、来源损坏或虚假证据仍不能采信。
- 原始候选的 `risk:null`、`assessment_status:pending`、未知事实、置信度、比较要素和工作队列保持原样。`assessment.overall.risk` 是运营已知结果等级；`assessment.known_findings.by_scope` 提供同一规则的模块等级。`risk_basis=known_findings_screening` 仅用于已有低／极低依据的筛查预判，不能为零依据补低。
- 有具体正面依据的中高风险保持原等级，不按候选数量、摘要关键词、相似图片数量或未完成项数量自动评级；单纯相似或权利存在不是已查明冲突。地域、当前效力和实际比较仍须依据原证据及审阅理由。
- “极低”须有覆盖相应整体范围的主审决定性排除；单一候选极低不会将整个产品变成极低。Generic 仅名称项按既有规则显示无风险。
- 主情景、条件性品牌复用、待审申请未来变化和维权信号分别展示。条件情景不替换本次主情景等级，未来申请不冒充当前已授权权利。
- 风险等级与 `status/business_completion` 分开。没有任何有效查询的模块可有政策标签，但查询状态必须写“未查询”，不能写成“完成查询且未发现风险”。完整率由唯一查询计划和真实验收计算，不是侵权排除百分比。
- 新政策本身进入完整输入摘要和每项审阅绑定。评级政策变化需新审阅总体、范围、限制及受影响评级单元；原事实、原文和比较可作为已有材料复用，但不能把旧评级签名改绑新摘要。原始未知仍不得改写为已核实。

## 保留原版本的历史任务

历史任务的评级、阶段性报告与不完整报告规则见 [legacy/risk-estimate-historical.md](legacy/risk-estimate-historical.md)；新任务不读。

## 情景预判：scenario-triage-v1

- `workflow-correction-v1` 增加必要范围审阅及未来信号资格校验，详见[必要审阅](workflow-correction.md#必要审阅)。下文“未来信号完成审阅”只适用于有依据的合格信号，不能免除有效当前权利的评级；旧无标记输入保留原计算语义。
- 主情景及条件情景分别评级。分流、双审、主审和行动按相同 scenario_id/scenario_sha256 绑定；不同情景不是同一争议的两个意见，不能合并取高、取中或共享授权推论。默认同结构选品情景及三类分流见 [业务流程](workflow-business-logic.md)。
- 只对有效入选、适用于该情景的候选作实质评级；未入选不需五级评级，也不是降低风险的法律证据。待补充、未审及未来信号分开计数；未来信号完成相应审阅，不重复要求当前评级。
- 已完成的未来/维权信号审阅使用 `future_signal:true` 或 `signal_only:true`、`assessment_status:assessed`、`risk:null`，仍提供完整理由及证据；不为关闭队列虚构当前等级。当前权利缺依据则仍为 `pending`，不能套用信号标记规避必要评级。
- `overall.risk` 表达主情景已取得证据支持的当前预判，与 `status/business_completion` 独立。没有有效依据时保持 null/pending，不默认中或低；已有中高风险不因其他范围未完成而隐藏，局部低／极低排除也不外推为全情景无侵权风险。此规则同时适用于新任务的总体、情景、权利范围与候选；历史任务继续按其冻结的策略读取。
- 情景置信度只由驱动结论的证据及可能改变该结论的缺口限制；无关范围缺口不降低已核实单项。已有 active 登记不能套用“缺状态事实”的模板。
- 未知许可不是降级反证；原卖家与权利人的关联不能证明新进入者获授权。真实许可只在其实际主体、地域、用途及期限范围内适用。
- 技术比较以“一个已描述实施方案 × 一项独立权利要求”为单位。每组独立保留要素和结果，不能将其他权利项的限制移入本项，或以另一用法不匹配抵消本方案风险。裸件销售、组合使用、方法实施及可能的间接侵权条件分别说明；不因产品对应专利或部分要素相似直接判高。
- 依赖结构比较的当前已评级专利须有实施方案及独立权利项表。`comparison.implementations[]` 声明 implementation_id/title/description/product_evidence_refs；claims 使用 implementation_id/claim_id/claim_type/conclusion，并逐项绑定证据。仅依赖已核实身份、地域、期限等决定性排除时，可用 `decisive_exclusion.basis=legal_status_or_scope` 与 `comparison_not_required_reasoning` 说明免做结构表的依据；不能用普通缺口省略比较。
- 报告首页同时显示情景、当前预判、置信度和必要工作完成度；条件情景单列，缺口与反证分开。完整章节和文件校验通过不证明检索完整。

以下等级定义、比较底线与双审要求继续适用有依据的结论；任何“必须选级”都不授权修改原始双审中的待评项。

## 1. 输出与等级

最终输出 `极高／高／中／低／极低` 风险及 `高／中／低` 置信度，表达现有证据下最合理的预判。原始权利状态、个别比较要素和来源记录仍可为 unknown；不能把这些原始未知改写成已核实事实，也不能把“无法判断”作为本策略最终等级。

- **极高**：具体适用权利与拟售产品高度对应，关键侵权构成有直接证据，没有有力排除依据。
- **高**：正面证据明显占优，主要保护内容高度对应，现有反证不足以改变风险判断。
- **中**：存在具体、可信的权利冲突线索，同时保护范围、权属或产品差异存在可能改变结论的争议。
- **低**：排除依据占优，或已完成的相关检索及比较尚未形成具体威胁；保留残余风险和覆盖边界。
- **极低**：明确评价范围内有稳定、决定性的排除事实，例如某件专利期限届满。不得将单件候选的排除扩展成整个产品清白证明。

不按关键词命中数、图片相似百分比或文献数量打分。缺少资料不自动判中，相似图片不自动判高，检索无命中不自动判极低。只有失败请求而无有效搜索时，不得把“没有发现威胁”写成证据支持的低风险。主审仅在已有有效依据时选级，否则保留原始待评；未检索到的范围列为缺口。

## 2. 每项判断的六项说明

1. **等级和范围**：国家、权利类型、候选或已审素材、实际拟售行为、证据截至日期。
2. **支持风险的事实**：具体对应、保护内容与产品关系，以及证据引用；没有正面证据也应如实说明。
3. **降低风险的事实**：必要要素缺失、整体差异、地域、期限、授权或其他排除依据；没有有力反证应明示。
4. **主审推论**：比较正反依据后明确选级，解释为什么不更高、不更低。主审结论不是多轮意见的平均数。
5. **置信度和假设**：区分已核实事实、推断及尚未证实的条件，说明哪个缺口最可能改变判断。
6. **人工核查及调整条件**：列具体核查对象、适合核查者、建议材料；明确什么发现导致上调或下调。无需核查的候选可说明已具决定性排除事实。

每项可适当合并简短表述，但以上内容须能在统一评级数据与报告中追溯。范围未包含的未知品牌名称或 Logo 放入未纳入范围，不虚构候选、不拖累已完成产品外形评估。

## 3. 置信度与总评

以下为完整任务及历史策略的置信度标准；`partial-evidence-v1` 整体不完整时，单项、模块、情景和总体均显示低，不改变原审阅事实。

- **高**：主要事实与关键推论可直接复核，剩余缺口不太可能改变等级。
- **中**：主要证据可靠，但比较解释或部分事实仍有不确定性。
- **低**：依赖关键假设、权属未核实或存在有依据的实质分歧。

五因素 `confidence_basis` 保留身份、范围、状态、产品、比较的证据和缺口，但不机械加权。访问失败只影响其缺失事实或覆盖；可选来源失败不连带降低无关已核实事实的置信度。部分有效检索只能支持其实际覆盖范围内有比较依据的结论；`scenario-triage-v1` 不据局部未发现威胁外推全情景低风险，也不以低置信度替代必要的评级依据。

总体风险取**主审确认且适用于本次销售范围的最高当前风险**，不平均，不让多个低风险稀释一个高风险。总置信度取决于驱动总体等级的证据链，并计入可能改变总评的覆盖缺口；不得取所有候选置信度均值。同申请 A1/B1、重复网页、共同转载图片不重复增加风险；说明文献数量与独立申请/权利数量的区别。

两端等级仍需范围依据：若已评条目只有局部极低，不能将产品总体直接定为极低。整体极低须主审另给覆盖总体范围的决定性排除；`scenario-triage-v1` 缺少整体低／极低依据时，保留候选局部结论、情景保持待评，不自动补低。无新修订的历史策略才保留其原有总体低风险及置信度限制分支。具体候选的极低／高置信结论保持不变；有具体中高风险驱动时，不因无关未评范围自动降低该风险判断的置信度。

待审或未授权申请的未来变化、历史维权/投诉紧迫度单列补充；它们不凭数量或同类产品关联直接抬高当前侵权等级。已授权同申请应按实际授权权利单独比较；kind code 本身不证明现行状态。

## 4. 比较底线

- **专利/实用新型**：核对目标国家、实际权利状态、适用权利要求，逐必要要素对应产品；不因材料不同、摘要标题不同或缺某个从属限定就排除更宽的独立权利要求。没有足够要素依据时保留该具体推论限制，不能伪造全要素命中。
- **外观**：按对应国家的比较标准检查整体、实线保护内容、虚线声明、必要视图与关键差异。先前设计用于适当比较背景，不把普通观察者比较改成新颖性测试或自行宣告无效。缺视图时列明哪项差异依赖假设，不通过数图片宣称视图完整。
- **商标**：分别比较标识、读音、含义、商品服务、实际使用及来源混淆。相同类别不自动冲突，不同类别不自动排除；竞品页面品牌不等于用户自有品牌。
- **版权**：比较可保护表达、具体对应、来源/接触或复制线索、权属及授权。网页高度相似只证明对应线索，不自动证明其为原创作者或权利人；没有登记不等于无版权。用户拟售同款不等于准备复制卖家摄影、文案、包装或说明书。
- **商业外观/未注册权利**：按目标国核对来源识别、非功能性、必要的识别力/复制等条件、地域及期限，不仅凭造型相似定高风险。

原始法律入口：[USPTO 外观申请说明](https://www.uspto.gov/patents/basics/apply/design-patent)、[美国版权局一般问题](https://www.copyright.gov/help/faq/faq-general.html)。入口说明不能充当单案现行权利证明；具体事实仍绑定真实原文、图样和状态证据。

## 5. 独立复核、主审与补充核查

两轮绑定同一产品范围及证据快照，第二轮不看第一轮结论；主审在两轮完成后读取双方理由。重点检查拟判极高/高风险、拟判低/极低风险和决定性排除。

有分歧时定位到同一情景、候选、实施方案与要素、状态或整体差异，优先使用已有证据解决；有必要且可执行的新取证才重新冻结对应输入。仍有实质分歧时，主审记录双方有效依据、自己的选择及不确定性；依据足够才明确五级之一，否则保持待评。不以多数票、平均等级、默认从高或无限追加复核代替主审。

报告可列专业人士复核或供应链独有资料核查，用于提高置信度、确认规避/授权或调整等级；这些是已给出当前预判后的具体注意事项，不是拒绝评级的前提。自动检索、取证、翻页和证据比对仍由 Agent 完成，不让用户代做。

## 6. 发布与真实性

新策略仅替代“缺口或分歧使风险归空”的历史结论门禁，保留来源支出 0 USD、访问边界、产品身份、证据引用、原始媒体及计划哈希约束。`低置信度` 不能豁免伪造截图、错号引用、不同产品混用、无来源事实或哈希不符。

报告首页同时展示总风险、置信度、驱动理由、`risk_basis` 与适用范围。七个权利模块、未来申请和维权补充保持可区分；“发布阻断项”展示位置改为“人工核查与注意事项”。`partial-evidence-v1` 的证据不足不阻止不完整报告交付，但其低风险必须附“未排除侵权风险”，并逐项列出已查、命中、无命中、失败、未执行、截断和提交未知；八章、七模块与既有 CSS 保持不变。

显式重评写入新的输出目录，从同一份新评级数据生成 HTML、Markdown、CSV，保留真实截图、来源和哈希。旧意见、旧报告和冻结证据不改；评级变化说明源于规则/推论调整还是实际新增证据，不把重分类写成新发现。具体字段与命令见 [evidence-schema.md](evidence-schema.md)。
