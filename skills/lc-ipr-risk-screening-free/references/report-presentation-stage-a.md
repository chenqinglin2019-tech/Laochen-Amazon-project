# 10A 阶段报告呈现

## 运营版呈现

显式 `presentation_policy_revision=operator-report-v1` 与 `assessment_revision=known-findings-risk-v1` 使用运营版。新任务采用该标记；既有任务须有明确重评要求，不自动改版。总体与各地域权利结果只读统一评级结果，不在模板硬写低风险。候选 pending、unknown、未排除与原始置信度保持专业附录中的原意。

已确认的绿色运营版由 `assets/operator-report.css` 与 `references/report-format-lock.json` 固化：主页面依次为产品、当前结果、九类查询模块、重点候选、未完成事项、实际来源和详细资料入口，七章节不可省略。风险卡必须显示评级结果或有依据的风险待定，并显示动态评级置信度。九模块固定为版权、外观专利、发明专利、商业外观、图形商标、文字商标、实用新型、未注册外观、维权信号；每卡保留“查了什么／发现什么／尚未完成／运营关注”。仅固化布局与字段，不复用样例商品、案号、结论或百分比。模块分别列查询状态、已完成步骤、发现、缺口和运营关注；没有等级不推导未查询。本地资料调查有真实材料与完成记录时显示本地调查完成，不要求远程提交。查询完成率读取 `actual_query_execution_progress` 的真实任务完成投影；HTML、Markdown、CSV 和逐项明细共用该结果。分母为当前去重查询与资料核查任务，分子为有合格原始回执并完成结果处理的任务；重试、历史重复及被正式替代旧项不重复计数。失败、未提交、未知状态和未完成阅读处理不得计为完成；已初始化且 N=0 显示“不适用（无查询计划）”；计划尚未登记时显示“查询计划未登记”，不补 0/0 或百分比。侵权判断、事实缺口及最终双审状态独立，不能把形式台账未验收误显示为查询 0%。旧报告未带实际执行投影时保留历史快照。

主情景是当前明确拟售行为；条件品牌复用情景留在附录。Generic 参考名称免查与未提供自有品牌分别说明。制度不适用须读取已审制度判断，不靠模板按国家猜测。候选图证按相关性选择，低风险与待判断亦可展示，准确原件与 PDF 页绑定检查照常执行；缺图明示。国际公开同一文献可合并展示，地域判断单元保留独立，不能把国际公开自动称为美国权利。

运营正文约 4,000—6,000 中文字；不输出 JSON、代码、机器路径、内部 ID、可见哈希和审阅签名。准确案号、日期、来源链接及图文比较保留。完整候选和逐要素比较在 `operator-appendix.html`，完整技术数据在 `technical-audit.html` 与 `report-data.json`；`query-progress.html` 展示逐项查询完成记录、中文完成依据、精确查询编号与执行回执编号以及原始查询表达式和检索维度，便于对账；`query-progress.json` 保留精确来源与统计证明；所有附录独立交付并受 Manifest 字节哈希约束。显示报告阶段不等于宣称实际已送达，实际入口由 10E 固定版本交付收据验证。

## 历史呈现

新建任务使用 `report_presentation_revision=report-presentation-stage-a-v1`。报告层只读 09D 的同一阶段快照，采用历史样例的八区结构和 CSS 原始前缀，再按主 PRD M10-D002 衍生内容。历史样例文件和样式的 SHA-256 已登记在 `report-format-lock.json`；样例中的商品、数字和判断不得复用。

页面分开显示 09A 唯一工作项 C/N、09B 当前阶段等级与核实状态、09C 审阅状态、09D 来源／评级／审阅截点。没有有效判断、没有候选或 N=0 时分别显示未知／空状态，不能补零推断低风险。旧失效等级不得进入当前总评；中、高、极高的有效阶段判断优先展示当前产品图、对应权利图、比较和缺图影响，低／极低与未入重点的候选仍留追溯。七模块和五列候选表不生成第二套法律结论。

同一包的 HTML、按需 Markdown／CSV、JSON、Manifest 的当前总评由阶段快照投影；旧评估仍是重算与来源输入，不作为报告中的并行等级。10A 只处理内容与版式，业务完成／受限判定见 [10B](business-status-stage-b.md)，按类型文件见 [10C](report-package-stage-c.md)，独立校验见 [10D](delivery-inspection-stage-d.md)，实际本地入口／版本见 [10E](delivery-versions-stage-e.md)。旧任务未带此标记时保留旧渲染。
