# 版本记录

Skill 名字不变（lc-ipr-risk-screening-free），用版本号区分。老版的任务标识是 2.4-free。

## 3.0.0（开发中，2026-11-26 起）
重做的精简内核。目标：单个任务 8 分钟内、50 万 token 内；只要拿到了商品资料，任何情况都出一份报告。

- 第 0 阶段（2026-11-26）：骨架。一条命令、唯一的状态文件、四种结束方式、用时和 token 记录、五块结构的报告模板；用录好的一次真实任务数据（太阳笑脸证件扣）可以从头走到尾。真实的采集、检索、AI 会话还没接上。
- 第 1 阶段（2026-11-26）：从入口到产品理解接上了真实实现。云端鉴权（协议不变）；商品采集默认用 EGO 浏览器，没装用 Chrome，遇到验证码或登录停下等处理后续跑；资料入口（一张图加一句描述）；AI 子会话改用省额度的模型分档并精简了固定开销；产品理解一次给出具体叫法、要避开的泛称、功能特征和"可能属于别人的图案、角色、文字"，再对照常见维权方清单点名权利人。检索还没接上，所以报告里各类权利暂时都是"未检索"。
- 第 2 阶段（2026-11-26）：美国的检索和初筛接上了真实实现。发明和外观以美国专利局的公开检索接口为主（免费、当天授权当天可查），SerpApi 为辅；商标查 Signa；用主图以图搜图和维权信号网页检索走 Serper；几路同时查，十几秒完成。检索词用 AI 给出的"专利标题里的核心品名"，外观再顺着分类号查一轮。初筛成批做：文字一批（发明、商标、图案），看图一批（外观拼成带编号的拼图），看不清的补图再看一次；常见维权方清单点名的直接入选。比对和复核还没接上，所以入选的候选在报告里暂时是"没有比完"。
- 第 3 阶段（2026-11-26）：深查比对、复核和完整报告。入选的候选取材料后成批比对：发明逐要素对照独立权利要求（全部对应评高，有照片上看不到的评中，有不对应的评低），外观先看主体造型，商标和图案看是否实际使用和具体表达；评到中及以上或拿不准的另开一个看不到第一次结论的会话复核，两次不一致取较高的。报告明细里产品图和对方附图并排，列出逐条对照、需要人工核对的事和两次判断。一单 6~7 个 AI 会话，约 3~5 分钟。
- 第 4 阶段（2026-11-26）：出错和超预算时的表现。AI 额度用尽、接口连不上、到时间收口，都照样出报告并写明没查完的部分；把同一条命令原样再运行一次就接着做，已经查过的不重查（`--fresh` 重新开一单）；同一单不让两个窗口同时跑，两单可以同时跑。外观的图有三个来源互相顶替：Google 图库、美国专利局按页取图的接口（2026-11-26 晚它换了地址，已跟上）、专利局每周公报的网页；取过的图在本机留一份。
- 第 5 阶段（2026-11-26）：安装和分发。`install.py` 装依赖并自检（Python、图像库、Codex 登录、浏览器、后台鉴权、各 key 的余量、网络）；分发包只带运行要用的文件，不带密钥、虚拟环境、样例和测试；SKILL.md 压到 5KB 以内。

## 3.1.0（2026-11-27）
美国以外六国的检索接上了（第 6 阶段）。在真实接口上跑过德国一单（约 2 分钟、8~13 万 token）和日本一单（2.7 分钟、8.5 万 token）。

- 英、法、德、意、西：查本国加欧洲专利局的已授权发明；德、意、西的实用新型另查一次（登记了不算"已授权"，和发明一起查不出来）；法国的实用证书随发明一起回来。日本：查发明、实用新案、意匠。检索词带当地语言的叫法。都走 SerpApi 的 Google Patents：英、法、日每单 2 次，德、意、西每单 3 次（有欧盟账号时少 1 次）。
- 欧盟外观（法、德、意、西）：`.env` 里填了欧盟知识产权局的账号（EUIPO_CLIENT_ID、EUIPO_CLIENT_SECRET）时走它的官方接口，按品名检索、按视图取图，和美国外观一样看图初筛和比对；没填或没查成时退回 Google Patents，只有名单没有图，报告里列名单和官方链接、写"未能比对"，这一类不评低。
- 日本意匠在 Google Patents 上没有图：只列名单，写"未能比对"，要到 J-PlatPat 按登记号查看。
- 查不了的本国库逐项写"未检索"和原因，那一类不评低：英国外观，德、法、意、西本国外观，德国本国商标，日本商标（产品上有文字时）。产品上的文字不是拉丁字母时商标写"未检索"。
- 各国的保护期按各自的规则推算；欧洲专利页和机器翻译页面（日文、德文原文）的权利要求都能读出来。报告里写明：欧洲专利在目的国是否仍然有效没有核实；机器翻译的权利要求用词可能不准。
- 一个数据源都接不上、也没有商标词可查时，总评写"待定"。
- 文字初筛：AI 给了一个这一批里根本没有的类别的编号（比如没有图案候选却答了 A01）时不再整批作废。
- 安装自检多一项"欧盟知识产权局的账号"（没填只是提醒）。
- SKILL.md 的标题写上当前版本号（原来升到 3.1.0 后标题还是 v3.0，在 Codex 里问版本会答成 3.0）；打包时会核对。
- 在 Codex 里显示中文名"易逊-侵权查询免费版"（`agents/openai.yaml`；Skill 的英文名字不变）。
- 安装时自动摘掉老版（2.x）留在 Codex 里的钩子：换成新版后它们要运行的 `scripts/codex_guard.py` 已经不在了，留着会把 Codex 里的每条消息都拦下并报"can't open file …codex_guard.py"。只摘文件已经不在的那几条，先备份 hooks.json，别的钩子不动；自检里也会报出来。
- Chrome 采集：过完验证码或登录后 Amazon 把页面带到首页时，自动回到商品页再读（原来会报"没有找到商品标题"）。Windows 实机发现。
- 欧盟官方接口：通行证没取到时两分钟内不再重复去取；被提无效但还在审的外观仍算有效；这次没取到图的欧盟外观，再运行同一条命令会补取。
