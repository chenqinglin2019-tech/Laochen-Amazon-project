# 易逊-侵权查询免费版 安装说明（版本号见文件夹里的 VERSION 文件）

## 先准备好

| 要有的 | 说明 |
|---|---|
| Python 3.9 或更新的 | Mac 自带的可以用。Windows 请装 python.org 的版本（不要用微软商店版），安装时勾上"Add python.exe to PATH" |
| Codex，并已用 ChatGPT 账号登录 | 在终端里运行 `codex login status` 能看到 Logged in |
| EGO 浏览器（已完成首次引导） | 没有的话要装 Google Chrome 和 Node 22 或更新的，安装脚本会改用 Chrome 采集 |
| 你自己的后台 token 和几个数据源的 key | 填在下面第 3 步的两个文件里 |

## 安装

1. 把压缩包解压到 Codex 的 Skill 目录下，得到 `lc-ipr-risk-screening-free` 文件夹。
   - Mac：`~/.codex/skills/lc-ipr-risk-screening-free`
   - Windows：`C:\Users\<你的用户名>\.codex\skills\lc-ipr-risk-screening-free`
   - 如果那里已经有老版本：先把老的文件夹整个**移到 skills 目录外面**留着（比如移到桌面），不要直接覆盖，也不要改个名字留在 skills 目录里（两个版本同名，Codex 会分不清）。
   - 老版本在 Codex 里登记过几个"钩子"（每次发消息时会去运行老版本里的一个文件）。换成新版后那个文件没有了，不处理的话 Codex 里发什么都会被拦下，报 `can't open file …codex_guard.py`。下面第 2 步的安装脚本会自动把这几个失效的钩子摘掉（原配置先备份），装完把开着的 Codex 关掉重开一次。
2. 打开终端（Windows 用 PowerShell），进入这个文件夹，运行安装脚本：
   - Mac：`python3 install.py`
   - Windows：`py -3 install.py`（提示找不到 py 就用 `python install.py`）
3. 安装脚本会在文件夹里建两个空文件，把你的 key 填进去再保存：
   - `config.json`：把后台 token 填在 `"backend_token": ""` 的引号里。
   - `.env`：`SERPAPI_API_KEY=`、`SERPER_API_KEY=`、`SIGNA_API_KEY=` 后面各填一个。Mac 上这个文件默认看不到，在访达里按 `⌘ + Shift + .` 显示。
   - 要查法国、德国、意大利、西班牙的单子时，`.env` 里再填 `EUIPO_CLIENT_ID=` 和 `EUIPO_CLIENT_SECRET=`（欧盟知识产权局的接口账号，在 dev.euipo.europa.eu 免费申请）。填了，欧盟外观才能取到图、做看图比对；不填也能跑，欧盟外观只列名单。
   - 如果你有老版本：这两个文件可以直接从老版本的文件夹里拷过来。
4. 再运行一次自检：
   - Mac：`python3 install.py --check`
   - Windows：`py -3 install.py --check`

   每一项前面是 [通过] 就可以用了。[没过] 是必须处理的，后面写着怎么处理；[提醒] 不影响使用（比如某个 key 没填，那一路就不查，报告里会写明）。

## 用

在 Codex 里说"用侵权风险快查查一下这个链接：<Amazon 链接>"。也可以自己在终端里跑：

- Mac：`python3 run.py --url "<Amazon 链接>"`
- Windows：`py -3 run.py --url "<Amazon 链接>"`（或 `python run.py …`）

用哪个 Python 命令来跑都一样：安装脚本把要用的东西装在了这个文件夹的 `.venv` 里，`run.py` 会自己换到它里面跑。命令结束时会打印一段"结论摘要"和报告的位置。

报告和中间文件放在你的用户目录下的 `ipr-runs` 文件夹里，一单一个子文件夹，报告是里面的 `report.html`。

## 常见情况

- **Windows 提示鉴权程序被拦**：在这个文件夹的 PowerShell 里运行 `Unblock-File tools\bin\*.exe`，再自检。
- **Windows 上自己把输出存成文件、打开是乱码**：输出被别的程序接走时是按 UTF-8 写的，用记事本打开时选 UTF-8；或者先运行 `$env:PYTHONIOENCODING="gbk"` 再跑命令。
- **配置文件用什么编辑**：记事本就行。注意引号、逗号、等号都要是英文的。
- **装图像库很慢或失败**：先设镜像再重跑安装脚本。Mac：`export PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple`；Windows：`$env:PIP_INDEX_URL="https://pypi.tuna.tsinghua.edu.cn/simple"`。
- **Amazon 要验证码或登录**：命令会停下并说明。在弹出的浏览器里处理完，把同一条命令再运行一次。
- **提示 AI 额度用尽**：命令会给出恢复时间。到时间后把同一条命令再运行一次，已经查过的不重查。
- **报告里有的外观写"未能比对：没有取到附图"**：多半是网络一时不通，或者美国专利局的取图接口那会儿不给图。过一阵把同一条命令再运行一次，只补这几件。
- **换电脑**：在新电脑上重新走一遍上面的安装步骤。不要把整个文件夹（含 `.env`、`config.json`、`.venv`）打包发给别人。
