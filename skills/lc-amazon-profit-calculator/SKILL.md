# 易逊-亚马逊商品毛利计算 · v2.1

目标：链接 → 自动取数 → Codex 内填写 → 双仓储情景与自动保存。历史 PRD 和 `references/legacy/` 不参与新任务；旧 JSON 保留原计算入口。

## 默认工作方式

1. 阅读 [采集流程](references/workflow.md)。提取对话里已有参数，调用单 ASIN 详情工具，缺字段才读商品页。不调用关键词、趋势、评论工具。SA 读取本站商品页，不能用 AE 替代。
2. 采用链接商品/变体测算同款或同类，记录参考来源。包装尺寸/重量优先；商品尺寸/净重可作标注的近似值。无法读取的价格、尺寸、重量、类目等保留空值，在页面补填，不编造。
3. **常规经营参数不在聊天追问**。采集后立即启动页面，即使采购、报价、退货率没有提供。已提供参数预填，完整时直接显示结果。采购按每销售包装、默认人民币；头程至少一条元/kg报价；退货率不能从评论推断。
4. 广告 10%、退货不可售 20%、仓储 90 天为可见默认值，本次修改不改变团队默认。采购、报价、退货率无默认数值；空白海运行只是填写入口。
5. 头程作为到仓综合报价，不追问清关、最低收费、进位、税费、卖家主体、账户资格，不采集外箱、装箱数量或间隙。
6. 不询问运输日期。始终同时计算淡旺季**仓储情景**，采用同一常规 FBA 配送费；仓储无季节差价时两者相同。

## 启动与打开页面

Agent 负责自动采集及核验费用，代码负责准备、计算和保存。保存 `bundle.json`，其中 `raw` 为商品详情、`user` 仅已有经营参数、`product` 可补充页面资料。字段见 [输入契约](references/data-contract.md)。

```sh
node <SKILL_DIR>/scripts/cli.cjs identify '<Amazon URL>'
node <SKILL_DIR>/scripts/cli.cjs ui <TASK_DIR>/bundle.json <TASK_DIR>/result
```

`ui` 输出 `status: ready`、本地 `url` 和目录。**随后调用 `open_in_codex`，target 为 `{type:"browser",url:<返回的完整URL>}`**，在本聊天的 Codex 内置浏览器打开。不能只给文件链接，也不要用 `target.type=file` 打开源码替代填写页。若返回 queued，可用内置浏览器读取状态确认；确实不可用才说明限制并提供本地 URL。

- 缺手填项也正常打开，启动成功退出码 0。无需用户回到聊天提交答案或确认完成。
- 信息完整时直接计算；更改后约 500ms 自动保存，按钮“计算并保存”立即保存。未齐全显示草稿，不展示过期毛利。
- 平台费率或汇率缺项由 Agent 补充，不让用户填写费表。可先运行 `prepare` 检查取数，并用 `QuickProfit.preflight(input)` 探测经营参数缺失时的规则覆盖；探测值不会进入用户输入或报告金额。
- 相同输出目录复用服务/草稿；新任务或新商品使用不同目录。重启恢复权威 `ui-state.json`，不会用原 bundle 覆盖用户填写。服务仅本机可用，关页后约 30 分钟无请求退出；再次 `ui` 恢复。
- `input.json`、`result.json`、`report.html` 随保存更新，`ui-state.json` 保存版本和草稿。后续读结果前检查 `scenarios`/`missingItems`，不要将草稿当完整测算。自动保存限在线填写页；独立 HTML 是可调参离线快照，修改需导出。
- 本地 URL 的会话令牌不写入可分享报告。详细会话与失败恢复见 [页面会话](references/ui-session.md)。

## 费用与异常

按需读取 [计算口径](references/calculation.md) 和 [站点覆盖](references/marketplaces.md)。仅采购、头程、佣金、FBA、基础仓储、广告和退货损失进入主指标；其他列为“本测算未包含”，不称实际为零。

- 普通商品站点必要价内销售税还原一次，特殊税率先自动查规则。不做企业税务访谈，不另加广告/平台服务税。
- 头程系数默认快递 5000、其他 6000；FBA 独立匹配站点规则。
- 退货按留存销售包装分摊，不重复扣退款本金、广告和采购；季节仓储变化影响报废分摊。
- 新任务自动检查 7 天费率、24 小时汇率缓存。`refresh` 只在来源内容与已审定 hash 一致时延长核验日期；变更/空壳/登录页由 Agent 核验，不伪称更新成功。已知失效规则阻止计算。
- 可用有来源的第三方费用估计并标注；无关键依据保持缺项。无法刷新可标注原检查日作条件参考，不称最新。
- AU 非零退货率仍需可靠退货处理规则；SA 处理费为有来源保守估计。更换表单不改变这些边界，不宣称所有站点所有费用全覆盖。

## 兼容与交付

代码仍支持 `prepare bundle.json input.json`、`run bundle-or-input.json output-dir`、`refresh SITE`；批处理缺项退出码 2、格式错误 1。正常新任务不使用 `--offline` 跳过新鲜度检查；冻结 v2 快照复算和测试可以离线。`schemaVersion:"2.0"` 保持不变，2.1 是 Skill/界面版本。旧 v1 继续 `calculate/report`，不静默迁移。

页面打开后简短说明在表单中填写即可；有结果时说明两季毛利、毛利率和差额，提供报告。不要把核验过程或问卷放在结果前。验证命令与边界见 [验收](references/acceptance.md)。

产品设计、字段约束及完整验收标准见 [详细 PRD v2.1](references/product-prd-v2.1.md)；日常执行优先阅读上面的操作流程。
