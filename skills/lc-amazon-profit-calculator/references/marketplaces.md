# 站点费率覆盖与来源

所有站点均保留链接识别、输入准备、独立计费匹配、双仓储情景和缺项输出。内置费表覆盖普通商品常见标准包装；不是所有危险品、超大件、特殊税率、细分类目及账户计划的完整费表。超出范围由 Agent 自动补对应规则，不外推最后一档。

## 数据路线验证

`tests/fixtures/collected/` 保存10站卖家精灵真实详情返回的必要字段，SA保存真实商品页的缺货/缺价状态。部分站点同一ASIN无售价或包装，验证的是“真实工具返回→正确站点→显式缺项”，不是假装11个商品都有完整实时参数。

常规/边界费率另以明确的测试包装逐站对照官方费表。人工边界输入只用于测试，不冒充真实商品尺寸；US鞋子另有完整真实参数报告。

## 费率扩展

需要新尺寸/类目时优先官方公开帮助/费率卡/收入计算器，其次有来源第三方估计。补写费率包、source、checkedAt、相邻档位测试后再运行。账户资格未知时采用有依据的保守费用，不新增账户问卷。仍无关键费用依据就输出缺项和可用的已知参数，不伪造全套毛利。
