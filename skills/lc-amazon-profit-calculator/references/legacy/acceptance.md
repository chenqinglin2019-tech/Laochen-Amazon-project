## 实现边界

- 没有独立自动抓取全部费表的服务，使用当前 Agent 的工具与官方网页；无需提供私密 API 密钥给 HTML。
- 复杂物流分配和无法表达的特殊费率退到严格绑定人工单件金额，变更条件后重新确认，不声称所有任意收费公式都已适配。
- 预设以本地 JSON 和编排流程管理，没有独立预设管理 UI。入库方案通过完整方案测算和总成本比较选择，没有独立方案推荐服务。
- 固定手工费用采取保守绑定，可能使部分敏感性场景提示需要更新规则；补充官方相邻档位后才能扩大离线可调范围。
- v1.2 待评审条目按正文实现；不可回收所得税预扣单列扣除后余额，G 定义不变。
