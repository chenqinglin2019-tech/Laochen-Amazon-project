# 采集、预设与追问

## 数据路径

1. 用户本次资料 → 同一子 ASIN 历史数据 → 当前单商品详情工具 → 官方只读网页 → 人工补填。价格、促销、包装、类目分别保留来源与时间。
2. 当前环境可发现 `mcp__sellersprite_mcp__asin_detail`，参数为 `asin`、`marketplace`。调用前重新发现工具声明，不硬编码连接器地址或凭据；其当前枚举含 US/JP/UK/DE/FR/IT/ES/CA/MX/AU，**不含 SA**。不调用详情趋势、关键词或市场工具来完成简单单品采集。
3. 详情接口返回的浏览类目不是收费类别，商品尺寸不是包装尺寸，第三方 FBA 金额只做对照，第三方毛利率不用于最终计算。缺失或父 ASIN 返回时继续确认。
4. SA 使用 amazon.sa 对应商品页面、官方沙特费表或用户资料。没有 SA 路径实测时标明未验收，绝不改成 AE。
5. 浏览器仅在工具不够时使用；读取该环境相应浏览器 Skill 并沿用用户权限。验证码、登录要求或连续两次同原因失败即停止重试，保存已得字段并转人工。
6. 费率 / 税务用 Amazon 官方、税局、海关；第三方用于找线索。汇率保留 CNH 货币对、方向、时间和交叉链，没有可靠报价则询问用户采用的可核实离岸报价。

## 状态

- 待采集：尚在读取资料，不可得出完整性结论。
- 待补信息：缺必填、无效输入、冲突或未经确认的假设；可显示已确定单项费用，但不显示合计毛利或排名。
- 可计算：该渠道必填与规则齐全。数据真实核验程度另见来源及站点验收，不把此状态宣传为全站自动验收。
- 条件估算：用户明确接受替代资料、过期报价 / 未来费率沿用、排除适用费用等；不以此绕过缺采购或缺物流金额。
- 需要更新规则：离线变化超出日期、价格、尺寸、资格或人工金额绑定范围；隐藏旧结果。

主指标与渠道比较独立。只要当前渠道可计算，可输出主指标；任何参与渠道未完整时禁止完整比较排名。

## 追问顺序

第 0 轮仅在身份有歧义时询问站点、子 ASIN、销售单位。说明“1 个销售单位 = X 件实物”，再采集其他字段。

第一轮自动采集和预设匹配后，回显已取得的价格、包装、类别证据，再集中编号列出全部已知缺项：

- 商品：实际成交价与币种；价内 / 价外税；是否已经扣优惠；包装长宽高、毛重及原始单位；收费类别和带电 / 带磁 / 液体等属性。
- 经营：每销售单位采购人民币成本；是否含包装、标签说明书及送货代交货点国内运费；广告占比及分母 / 是否含服务税、促销；退货率分母及成熟统计区间；r>0 时不可再售比例；单件入仓到售出的停留天数。
- 物流：快递、空运、快船、慢船报价；单价、币种、单位、线路、货物属性；比较 / 进位范围与步长；最低计费重及最低收费的金额与范围；分泡客户承担比例；燃油、旺季、偏远等附加费；包含 / 不包含 / 实报实销边界；报价日期及有效期；外箱长宽高、毛重、销售单位数，按票收费时每票箱数。
- 税务：按实际规则需要收集卖家设立地、主体类型、税务注册 / 计税方式、费用服务税抵扣、进口主体与凭证、所得税预扣回收性。只收资格，不收完整税号。价外买家税不因地区而无意义追问。
- 可选费用：促销与推广（活动参与费、兑换费、Vine、站外 / 联盟）、收款提现和结汇价差、EPR 等合规分摊。逐项填金额、确认不适用或明确排除。

后续轮次只问剩余缺项和新依赖，保存所有已回答字段。每轮先回显已记录值、单位和口径，纠正时保存覆盖历史。

## 有歧义与不知道

- “快递 38”：保存待确认原文，询问是否人民币每公斤、进位 / 最低收费和包含范围；不能自行将 38 写入正式报价。
- “¥”“广告 10”“含税”：分别确认币种、百分比或单均金额、销售税 / 关税 / 进口税 / 服务税。
- 用户不知道采购或物流价：只能由用户提供估计，不由 Skill 编造。退货和广告仅在有可追溯参考数据且用户明确采用后作为条件估算。
- 多数值可保存为命名场景，但每个场景仍须完整。报价单可提取后回显确认；未识别条款不视为不存在。
- 退货分母是留存销量时转换 `r=x/(1+x)`；部分退款 / 多次转售 / 残值生命周期超出范围。无退货退款若用户选择简化并无平台赔付，可归入退货并按不可再售，但须明确假设。
- 后台在库平均库龄不等于停留天数；不按固定比例静默换算，要求用户提供或确认估计。

## 日期与确认

默认展示而不重复问：测算日、默认发货和入仓日、专业销售计划、物流系数、当地 FBA、普通本地消费者。按站点当地日期解释，不能读取主机时区替代。

以下必须有确认记录：竞品替代、自有包装估算整箱、过期或未来费率延用、人工金额适用范围、适用费用排除、库存跨费率 / 旺季边界日期。用户已经明确给定即构成确认，不再次索要许可。

没有运输时效，各渠道同库存区间；用户给时效后，入仓=发货+时效，出库=入仓+停留天数（或明确代表出库日）。不按渠道名称推断时效。

## 预设使用

严格匹配站点、线路、货物、币种、包含范围、有效期；多匹配由用户选，不取最新一条猜测。有效期未注明每次确认。税务资格每次回显一次确认仍有效。

商品级采购、广告、退货、u、库龄、装箱资料只在同子 ASIN 中带出并确认。当前用户明确输入优先于预设；预设永不覆盖当前值。跨渠道比较前统一税费边界。
