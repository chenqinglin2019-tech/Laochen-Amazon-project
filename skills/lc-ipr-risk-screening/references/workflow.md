# Workflow

1. 输入：`references/input-routing.md`（完整商品采集，仅限美国）。
2. 发现：`references/us-workflow.md`（公开网页检索 + 云端知识产权候选发现）。
3. Amazon HTTPS 主图可直接使用；本地主图由 `us-screen` 经专属后端上传。上传失败时不得假装图搜已完成。
4. 对候选工作区执行一次全批次处置，再完成七模块审阅。
5. 查询覆盖、候选完整性、七模块审阅和 release gate 全部通过后输出风险筛查报告；否则输出带明确缺口的 draft/incomplete。

本流程不包含官方登记或法律状态浏览器核验，不输出官方法律状态确认，也不替代律师意见。
