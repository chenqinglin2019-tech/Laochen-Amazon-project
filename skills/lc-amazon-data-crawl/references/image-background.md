# 日常 Chrome 后台找同款

找同款使用 OpenCLI 绑定日常 Chrome 的一个工作标签，读取图片网址，在同一标签进入 Amazon `/stylesnap?q=…` 相似搜索，随后运行既有 Embedding → Mini 判定。默认每来源最多 48 个候选；结果只代表采集范围。没有系统鼠标、窗口激活、新标签、图片上传或测试浏览器路径。

## 开始前：确认退出卖家精灵登录

每次真实启动必须提醒：

> 开始找同款前，请先退出卖家精灵账号登录，并保持插件启用。找同款按未登录方式运行；确认退出后才会开始查询。

- Codex 必须先取得用户本次任务的明确退出确认，然后才可以传入 `--confirm-sellersprite-logged-out`。不能从用户要求“开始采集”、历史确认或默认配置推断已经退出。
- 终端交互运行可输入 `YES`；后台／unattended 没有显式确认则退出 30，且不发送查询。
- 确认只用于本次进程。不要把确认标志默认写入自动任务、配置模板或永久快捷命令。
- 不替用户退出或登录。DOM 明确显示仍登录时停止；没有可靠公开标识则只报告 `user_confirmed_only`，不声称已验证退出。
- 插件保持启用。找同款不打开产品查询面板，不补抓需要登录的销量、销售额等插件指标，不调用插件导出。
- 店铺／关键词仍按各自流程检查登录；不要把退出要求扩展到这些模式。云端 skill 鉴权与插件登录完全独立，照常执行。

## 配置、输入和入口

从 `assets/config/amazon_image_competitors.json` 创建新配置、新 `job_id`。新增或固定字段：

- `browser_backend: "opencli"`、`search_strategy: "sellersprite_stylesnap_url"`。
- `entry_mode: "batch"`（默认）使用 `products_file`；`"current_tab"` 捕获当前商品页，输入快照存入任务目录的 `current_tab.csv`。
- `max_candidates_per_source: 48`、`max_competitors_per_source: 48`。前者约束采集，后者仅影响既有 embedding/chat 判定模式；cascade 保持原来的粗筛和 Mini 语义。
- `result_mode: "count_only"`、`match_mode: "cascade"` 为默认。detail 也可使用 cascade，并输出来源状态页，早停或失败不能被误读成零。
- `sellersprite_required`、`sellersprite_on_lens`、`enrich_accepted_results`、`activate_plugin` 必须为 false。拒绝旧 CDP、上传入口及插件字段业务筛选配置。

批量输入支持 `ASIN`、`商品URL`、`主图URL`。仅本地图片会逐行报错，要求补充 ASIN 或链接；有有效链接的旧文件可保留本地图片列，但不会读取该文件。ASIN 与商品链接冲突、跨站点链接和非公开 HTTPS 图片网址都会报错。商品输入优先取真实页面主图，只有公开图片网址的来源直接搜索。Amazon 图片恢复为原图网址；其他网址保留签名查询参数。

命令仍为 `image-competitor-dry-run` / `image-competitor-run`，macOS/Linux 用 `./lc-amazon-data-crawl.sh`，Windows 用 `.\lc-amazon-data-crawl.cmd`。

```sh
./lc-amazon-data-crawl.sh image-competitor-dry-run --config config/my-images.json
# 仅在用户明确确认本次已退出卖家精灵后：
./lc-amazon-data-crawl.sh image-competitor-run --config config/my-images.json --confirm-sellersprite-logged-out
```

`dry-run` 仅检查配置、输入、CLI 依赖及本地模型凭据，不连接浏览器、下载图片、搜索或调用模型。`sellersprite-check` 遇到图片配置也仅做此预检，不要求登录或打开查询面板。

## 后台行为、数量与风险

开始时选好同站点 Amazon 工作标签。绑定后固定目标 ID，后续可切去其他应用或标签。读取、导航和滚动都核对网址与文档标记；明确标签关闭、刷新或被改页立即停止；暂态读取失败按只读恢复规则重试，不能仅因读取超时就认定标签丢失。节流等待结束后再次检查，防止等待期间用户改页。

本机已核对的 SellerSprite 5.0.6 按钮会生成图片 URL 搜索地址并激活新标签，因此采用同标签等价导航，不点击原按钮，不读取插件运行变量。插件或 Amazon 页面变化时按异常停止，不自动改用上传。

按 DOM 顺序采集、ASIN 去重、排除购物车和插件注入卡片；达到上限保留前 N 个。有限滚动、连续无进展或明确空结果时停止，报告 `limit_reached` / `source_exhausted` / `no_progress` / `scroll_limit`。商品页和结果页都校验配置配送邮编，无法确认时请用户手动设置后 `--rebind`；不使用旧地址缓存。某些站点掩码或不显示完整邮编时也会停止，不猜测。

找同款使用独立频率策略，仍与本机其他采集共享持久化操作计数：supervised 间隔 4–6 秒，每 20 次休息 20–35 秒，每 100 次改为休息 1–2 分钟；unattended 间隔 8–15 秒，每 10 次休息 20–35 秒，每 100 次改为休息 2–3 分钟。百次休息替代短休息，不叠加；切换来源、任务或重启不重置计数。已经排定的休息或风险冷却保留原截止时间。店铺、关键词和类目频率保持原值。

导航、搜索、滚动和重试都计入操作次数；DOM 每 2 秒只读检查，关键字段连续稳定 4 秒且间隔、休息均结束才继续。最多滑动 18 次、连续两轮无新增或达到 48 个候选即结束的规则保持不变。没有插件下载，不适用插件导出频率规则。

验证码、限流、访问拒绝和插件账号异常保留全局暂停，Amazon 登录页照常停止。普通插件登录入口不算异常。仅使用 DOM／桥接可见证据，不声称监测到了未取得的 HTTP 状态。白页、超时、商品失效、图片不可识别不能写成零同款。明确无结果或完成有效模型判定才能输出零。

## 模型、恢复与迁移

来源和候选优先直接向模型传图片网址，搜索前没有图片下载。模型明确拒绝图片输入时才允许在内存中读取并转码，不落盘、不在浏览器上传；模型限流或坏 JSON 不触发来源图片读取。无可判定候选时不调用付费模型。

保留三层检查点：来源／图片身份、候选快照、逐次模型和最终结果。候选完整则恢复时不再查询浏览器；成功模型调用立即落盘；最终按来源分片提交并重建总表，防止中断造成重复累计。图片从 URL 改成内存数据不会改变来源 Mini 缓存身份。既有阈值、候选顺序和第 11 个粗筛命中早停规则不变，详见 configuration.md 的 Cascade matching semantics。

标签丢失后人工选好替代工作页，用 `--rebind` 重新绑定；没有完整候选快照的当前来源重采，已经完成的候选／模型进度仍按身份校验复用。

### 普通错误自动恢复

- 已记录导航意图的断点只核对原 target：仍在原文档可继续采集，已到达预期 ASIN／图片搜索地址则补记文档标记，不重复查询。未知页面、无目标身份、标签关闭或用户改页仍停止，不自动绑定其他页。
- 页面普通故障先按原页面重试策略处理（supervised 等 60 秒重试一次；unattended 分别等 2、5 分钟）。阶段仍失败或模型临时失败时，等待 20–35 秒，自动恢复同一来源一次；复用候选和成功模型缓存。恢复等待与来源重试预算持久化。
- 缺失图片身份的候选快照作废并重采，保留能够核对的模型缓存；输入、配置或指纹冲突不能靠删除断点解决。
- 同一来源连续两轮仍失败则留空数量、标记 skipped 并继续下一来源。连续 3 个来源失败或最近 20 个来源中有 5 个失败时停止，保留剩余任务，避免整体故障时反复付费。
- 来源结果提交、模型阶段提交、汇总重建和 Excel 写入遇到临时文件锁时，每 2 秒重试，最多 3 次；不重新运行浏览器或模型。磁盘不足、持续文件锁等问题保留断点并报告。
- 验证码、限流、访问拒绝、账号限制、凭据错误、需人工确认或工作页身份变化不进入普通错误恢复。用户主动中断仍立即停止；未识别的程序错误不无限重启。
- 重新启动命令会从断点接续；进程被系统终止后仍需重新启动命令，脚本不会创建常驻进程。

旧任务迁移使用 batch 和旧任务原输入；current_tab 使用独立的新任务。旧任务不能原地静默续跑。新配置、新 job_id 可加 `--migrate-from-job OLD_JOB_ID`：

- 旧任务保持只读；校验输入及顺序、站点、数量、配送地和模型指纹。
- 导入兼容结果分片或数量记录，以及身份可验证的未完成候选／模型进度。
- 不导入旧窗口句柄、上传状态和 Find Similar 回退标记。
- 旧本地图片只用于验证旧付费缓存身份，不作为新搜索输入；无法核对的进度列入迁移报告，不冒充缓存命中。

输出继续包含原数量／明细 Excel、`records.jsonl`、`candidates.jsonl`、`counts.jsonl`、`state.json`、`run_summary.json` 和 `run_heartbeat.json`。新增 `image_collection_report.json`；迁移时新增 `migration_report.json`。报告区分用户确认与 DOM 证据，记录来源图片身份、候选量、判定量、停止原因和模型调用／缓存复用统计。明细模式的插件字段缺失须注明，不能伪造为零。

## 维护验收

运行 `python3 tests/run_non_browser_tests.py`、`node tests/test_image_background_dom.cjs` 和现有插件 DOM 测试。真实 Chrome 验收必须在用户已确认退出后进行，使用固定目标验证两个商品来源和一个公开图片网址，并记录前台应用／标签事件。Windows 静态或模拟检查不能代替 Windows 实机结论。

此修改仅更新指定 skill 源码。现有 runner 使用 setup_runner 更新代码时保留配置、凭据和输出；旧配置应按本文显式迁移。

恢复时，如原固定标签已完整加载所需同一网址，先验证网址、页面身份与健康状态，再复用当前文档，不重复刷新；网址或页面身份被人工改变仍停止。

跳转回复丢失时，只读取原固定标签并核对已保存的 pending_navigation：确认达到预期 ASIN／图片查询且页面健康后接续；不得重复发送未知结果的跳转。原页未跳转、目标失联、跳到其他商品或出现风险时仍停止。

导航期间缺少 documentElement 时，未绑定文档身份的导航核对只报告 loading 并等待，不把暂态 DOM 当成永久故障。已绑定文档的身份校验不放宽。target_navigated / detached_mid_command / cdp_timeout / attach_failed / 本地进程读取超时进入共享只读恢复：间隔 2、2、30、60、120 秒，随后每 300 秒复核，累计最多 30 分钟。原 target 列表和 snapshot 读取均覆盖；写操作绝不自动重放。断线不消耗导航／稳定观察预算，恢复后重新计算连续稳定时间。到期返回 retry_later（20）并保留当前来源，不进入来源失败／跳过逻辑。日志只保留安全机器码，详见 [opencli-read-recovery.md](opencli-read-recovery.md)。


## 流式候选粗筛

- cascade 每批候选加载稳定后、下一次滚动前调用同一套 Embedding 粗筛。保留原 ASIN 去重、来源 ASIN 排除、候选顺序、最多 48 个候选、相似度阈值和不可识别图片规则。
- 累计视觉命中大于 `prescreen_max_matches`（默认 10，即第 11 个）立即结束当前候选采集，`collection_stop_reason=prescreen_limit_reached`；结果保持 `prescreen_excluded`，精确同款数留空且不调用 Mini。
- 尚未超过阈值的中间批次不生成最终数量、不调用 Mini，也不按中间批次的不可识别比例提前判失败。达到原采集结束条件后使用完整已采候选执行原验证逻辑。
- `lens-partial_collection.json` 只保存部分候选，不冒充完成采集。中断后复用部分候选和成功向量；正式 collection 写入成功后删除 partial。旧断点已有完整 collection / 模型结果则直接复用，不重新采集已完成产品。
- 模型调用计数覆盖流式粗筛和最终精判全过程。导航、滚动、稳定检查与累计休息策略保持不变；串行使用同一固定标签。

图片内存转码前的 DNS 解析失败或空地址结果属于普通网络故障，复用来源级有限恢复和已有模型缓存；不标成配置错误，也不缓存为候选图片不可识别。非 HTTPS、内网地址和非法 URL 仍拒绝，不放宽图片安全校验。日志保留异常类型及 errno，不记录凭据。

已确认到达预期 ASIN／图片查询的原标签，如主图或候选已出现但文档持续未完成加载，导航恢复等待超时后允许按原节流规则重新加载一次。操作前核对原 target、网址、文档标记和风险，重载预算发送前持久化，跨重启不重置；成功完成后清除。未知目标、无有效内容、验证码、身份变化仍停止，不重放结果不明的导航。一次重载仍失败则保存断点退出。

用户指定完成若干产品后暂停时，可在任务目录写入 `pause_after_count.json`，例如 `{"completed_count":100}`。在每次领取新来源前核对已提交结果数，达到阈值则保存输出、释放采集锁并退出；保留暂停文件，直到用户明确要求继续才移除。不得提前开始阈值后的产品。

macOS 系统 HTTPS 代理开启时，仅白名单内的 Amazon 官方图片 CDN 可通过该已配置的本机代理执行 HTTPS CONNECT，由代理解析域名，避免 TUN Fake-IP 被误判为图片配置错误。保留原域名及 TLS 证书校验，不直接访问虚拟 IP；每次重定向重新校验。其他域名和内网 URL 仍执行原公网 DNS 校验；不修改用户网络设置。

稳定性仅比较商品 ASIN／主图网址，或按 DOM 顺序排列的候选 ASIN＋图片网址及空结果状态；价格、评分和插件文字更新不重置计时。仍要求页面 ready、无 busy、连续稳定 4 秒，每 2 秒读取一次；ASIN、图片、候选顺序或加载状态改变均重新计时。此调整不改变匹配阈值、候选上限、两轮无新增、模型并发数和累计休息。

同一文档标记仍匹配时，只读检查允许同一 ASIN 或同一图片 q 查询的规范化网址改写，仅忽略 psc/ref/ref_/_encoding/tag/pf_rd_*/pd_rd_* 跟踪参数。其他查询参数、ASIN、图片查询、站点或文档变化仍停止；先更新已核对的网址再执行写操作。原标签失联须人工选页后 --rebind，不能推断历史改页原因。

候选图片转码结果按原图片网址保存在当前 runtime 的内存 LRU 缓存中，上限 64 MiB、128 项；后续粗筛与 Mini 复用同一图片数据和既有向量缓存。图片不落盘，不缓存读取失败；新进程首次仍可能读取一次图片，再复用已持久化向量。模型身份、判断阈值、候选顺序和全部节流休息规则不变。

商品页只读校验额外允许 th=1 的增加或移除，但必须同一文档、同站同 ASIN，且 input#ASIN 明确匹配；不忽略其他 th 值、重复 th、卖家参数或搜索页 th。网址／文档校验失败时，将前后网址（未知查询值脱敏）、文档标记、DOM ASIN、动作和 target 写入 state.json 的 last_page_identity_error，不改变停止条件。
